# Ay Işığı Wattpad Aktarıcı

Opera/Chrome eklentisi — Wattpad'ten bölümleri siteye aktarır.

## Kurulum (bir kez)

1. `npm run dev` ile site çalışsın
2. Opera: `opera://extensions`
3. **Geliştirici modu** aç
4. **Paketlenmemiş uzantı yükle** → bu `extension` klasörünü seç
5. Opera'da **VPN açık**
6. Wattpad kitap veya bölüm sayfasında sağ alttaki **Ay Işığı'na Aktar** düğmesine bas

Şifre: `Billy31?` (bir kez sorulur, hatırlanır)
